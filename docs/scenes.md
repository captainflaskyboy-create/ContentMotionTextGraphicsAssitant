# Scene version 1

The authoritative contract is [scene-v1.schema.json](scene-v1.schema.json), generated by `cmtga schema`. Unknown fields and unsupported versions are rejected. Every scene has `version: 1`, positive `duration` in seconds and ordered `layers`; later layers draw above earlier ones. Optional `canvas`, `theme` and `seed` have defaults.

Canvas: even width 64..3840, even height 64..2160, rational `fps: {numerator:30,denominator:1}`, hex `background`, and `bitrate_kbps`. Coordinates always use a 1920x1080 design canvas and scale with output dimensions. Maximum duration is 600 seconds; 1..512 layers, 4 MiB request size. Duration rounds up to the next frame boundary.

Each layer has unique `id`, `start`, `duration`, `x`, `y`, `width`, `height`, optional `motion`, and tagged `content`. Static bounds must fit the design canvas. Motion may deliberately move content beyond its static bounds. Images stretch to the requested bounds; preserve their aspect ratio when choosing those bounds. Images are limited to 32 MiB each and 32 million decoded pixels across the scene.

Content types:

| Type | Main controls |
|---|---|
| text | text, font, font_size, min_font_size, color, align, padding, wrap, typing_seconds, cursor, scroll_lines |
| rectangle | color, radius, stroke, stroke_width |
| line | color, thickness; the layer bounds define its diagonal, or a horizontal/vertical line when height/width is at most 4 |
| image | path to a local PNG/JPEG supported by Windows Imaging Component |
| counter | from, to, decimals, suffix, font_size, color, count_seconds |
| progress | from/to fractions, color, track, fill_seconds, easing (default linear) |

Text font aliases `heading`, `body`, `mono` select theme fonts; other values name installed font families. Alignment is left, center or right. Text aligns to the top; position its box to choose vertical placement. Fitting reduces size only when needed and errors if the minimum cannot fit. Terminal scrolling is capped by both `scroll_lines` and actual text overflow. Typing respects grapheme clusters.

Motion: `entrance`, `exit`, `easing`, `from_x`, `from_y`, `from_scale`, `to_x`, `to_y`, `opacity`, `reveal`, `glitch`. Entrance and exit must fit the layer duration. The intervening time is the hold. Entrance animates from offsets/scale/zero opacity; exit fades and moves toward its offsets. Reveal clips left-to-right. Easing: linear, out_cubic, in_out_cubic, out_back. Glitch is seeded horizontal jitter in logical pixels during entrance, bounded to 32 pixels; it never affects green background.

Theme fields: heading_font, body_font, mono_font, yellow, white, panel, muted, outline, outline_width, entrance, exit. Colours are `#RRGGBB`; content can reference the named theme colours. `text --theme` applies theme entrance/exit defaults to generated layers, capped to fit their durations. Explicit per-layer motion controls existing JSON scenes. The shipped theme is saved in `themes/captain-flasky-boy.json`.

Presets use different staging: rules slide numbered cards; impact scales typography against a wiped panel; terminal types and scrolls; counter combines changing numbers and fill; callout draws brackets; flowchart reveals nodes sequentially with connectors. Editing exported JSON provides full control without preset-specific runtime behaviour.

Batch version 1 uses `{ "version": 1, "jobs": [{ "request": "scene.json", "output": "scene.mp4" }] }`, with up to 100 jobs. Duplicate output paths are rejected. Each job produces an independent MP4.
